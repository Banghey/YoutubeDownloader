# 중2 세계사 · 한눈에 보는 시간 막대

2022 개정 교육과정 **역사①(세계사)** 흐름을 시간순 막대로 보여주는 교실용 웹 페이지입니다.

## 실행 방법

브라우저에서 `index.html`을 열면 됩니다.

```bash
# 또는 로컬 서버
python3 -m http.server 8080 --directory world-history-timeline
```

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 페이지 구조 |
| `styles.css` | 디자인 |
| `data.js` | 단원·사건 데이터 |
| `app.js` | 타임라인 동작 |

## 기능

- 선사부터 오늘날까지 **가로 시간 막대**
- 단원 색상·필터·바로가기
- 사건 클릭 시 요약·핵심 키워드
- 확대/축소, 드래그 스크롤
